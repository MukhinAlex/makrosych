# Макросыч

Программа для Windows, которая делает обработку таблиц Excel без программирования: вы описываете
задачу обычными словами, нейросеть собирает из описания сценарий, программа показывает результат
на вашем файле-образце — и дальше этот сценарий запускается на новых файлах одной кнопкой.

Аудитория — офисные сотрудники: бухгалтеры, аналитики, менеджеры, специалисты поддержки.
Никакого кода и «продвинутых режимов»: загрузили файл, написали, что нужно сделать, проверили
на образце, сохранили сценарий в библиотеку.

## Перед началом работы: подключите нейросеть

**Сценарии создаёт нейросеть — по вашему описанию.** В только что установленной программе
библиотека сценариев пуста: готовых заготовок в ней нет, потому что у каждой компании свои
таблицы и свои задачи. Первый сценарий вы составляете сами — для этого и нужна нейросеть.

Подключение настраивается один раз, на вкладке «Настройки»: адрес сервиса, название модели
и ключ доступа из личного кабинета сервиса. Кнопка **«Проверить подключение»** покажет, всё ли
в порядке, а **«Список моделей»** — какие модели предлагает выбранный сервис.

| Сервис | Что это |
|---|---|
| **RouterAI** (routerai.ru) — рекомендуется | ChatGPT, Claude, Gemini и другие модели в одном API, оплата в рублях |
| **Polza.AI** (polza.ai) | больше 400 моделей, пополнение картой российского банка |
| **OpenRouter** (openrouter.ai) | тот же принцип: модели разных производителей в одном API |
| **Локальная модель** (LM Studio, Ollama, llama.cpp, vLLM) | работает на вашем компьютере: бесплатно, без интернета, данные никуда не уходят |

Модель подойдёт любая, которая умеет следовать инструкциям, — например `upstage/solar-pro4`:
быстрая и недорогая. Названия моделей у разных сервисов отличаются, поэтому удобнее выбрать
из списка в настройках.

Платить нужно только сервису нейросети — за токены, которые уходят на составление нового сценария
(обычно от копеек до десятков рублей за один сценарий, зависит от модели и размера таблицы).
Автору программы платить не нужно. **Запуск уже созданных сценариев бесплатен**: нейросеть в нём
не участвует.

Ключ API хранится только на вашем компьютере, в `data/settings.json`, и не попадает
ни в экспортируемые сценарии, ни в журналы, ни в интерфейс после сохранения.

## Что можно поручить сценарию

Сценарий — это запись однажды описанной работы: какие данные взять, что с ними сделать и куда
положить. Он собирается из готовых операций, поэтому сценарию можно поручить, например:

- **Добавить и перенести данные.** Собрать значения из нескольких строк или из нескольких выгрузок
  в один шаблон; сложить несколько значений в одну ячейку через `;` или перенос строки.
- **Подставить данные из другого файла (ВПР).** Наименования и цены из прайса — по коду товара,
  с учётом регистра и пробелов; чего нет в прайсе, видно в журнале и в отчёте.
- **Посчитать и подвести итоги.** Сумма, среднее, количество, число различных, склейка дат.
  Есть и расклад как в Excel: строки данных, после каждого артикула строка «X Итог», в конце
  «Общий итог». Строки-итоги готовых отчётов («Итого», `ПРОМЕЖУТОЧНЫЙ.ИТОГ`) не считаются данными.
- **Навести порядок в ссылках.** Собрать ссылки из нескольких колонок в одну ячейку, разделить
  их переносом строки или `;`, превратить в активные гиперссылки с понятным текстом.
- **Скачать файлы по ссылкам из таблицы.** Обычные ссылки, Яндекс Диск, папки — в отдельные папки
  по артикулам, с отчётом: что скачалось, а что нет.
- **Вставить фото прямо в таблицу.** Картинки по ссылке (обычной, с Яндекс Диска, из файла или
  из папки на диске) встают в ячейки; строка и колонка растягиваются под фото, WebP преобразуется
  в понятный Excel формат. Рядом — активные ссылки на большие файлы.
- **Записать формулы Excel.** `=B{row}*C{row}`, `=SUM(D2:D{last})` — номера строк программа
  подставляет сама, поэтому формула всегда попадает в строку своего товара.
- **Обработать несколько файлов за один запуск** — например, таблицу товаров и прайс.
- **Собрать результат в ZIP** и показать отчёт о том, что получилось.

Если ваша задача в список не попала — опишите её своими словами: сценарий собирается из готовых
операций, и нейросеть подберёт подходящие.

## Требования

- Windows 10 или 11 (64-бит); на 8.1 может работать, но не проверялось. На Windows 7 не работает
- **Права администратора не нужны.** Отдельная установка PHP тоже не нужна: PHP и библиотеки
  лежат внутри программы.
- **Интернет и подключённая нейросеть** нужны, чтобы составить новый сценарий, и для сценариев,
  которые сами скачивают файлы. Уже созданные сценарии работают офлайн.

## Установка и запуск

1. Скачайте `makrosych-<версия>.zip` со страницы [Releases](../../releases) этого репозитория.
2. **Разблокируйте архив до распаковки.** Правой кнопкой по скачанному файлу → «Свойства» →
   внизу галочка «Разблокировать» → «ОК». Windows помечает файлы из интернета, и без этого
   шага часть файлов может не запуститься.
3. Распакуйте архив в свою папку — например `C:\Макросыч` или «Документы\Макросыч».
   **Не в `Program Files`** (там нельзя писать данным) **и не в папку OneDrive** (данные уедут в облако).
4. Запустите **`Макросыч.exe`**. Откроется страница в браузере, а в области уведомлений появится
   значок Макросыча.
5. Остановка: правой кнопкой по значку → «Остановить и выйти», либо `stop.bat`.
   Закрывать окно браузера можно в любой момент — программа работает, пока живёт значок.

Ярлык на рабочий стол: правой кнопкой по значку в области уведомлений → «Создать ярлык на рабочем
столе». Либо правой кнопкой по `Макросыч.exe` → «Отправить» → «Рабочий стол (создать ярлык)».

### Если Windows не даёт запустить программу

| Что видно | Что делать |
|---|---|
| «Windows защитила ваш компьютер», «Неизвестный издатель» | «Подробнее» → «Выполнить в любом случае». Так бывает у любой бесплатной программы без платной подписи кода |
| Компания запрещает неподписанные программы | Запустите **`start.bat`** — он делает то же самое, но с окном консоли (окно сразу сворачивается в панель задач) |
| Ни `.exe`, ни `.bat` не запускаются | В очень закрытых компаниях политика запрещает и то и другое. Попросите ИТ-службу разрешить папку с программой: ей нужны только права на чтение файлов программы и запись в папку `data` |
| «Макросыч не запустился за 30 секунд» | В сообщении указаны два журнала: `makrosych-launcher.log` (что делал лаунчер) и `makrosych-server.log` (что говорил сервер) — оба в папке `%TEMP%`. Запустите `start.bat`: он покажет сообщение об ошибке прямо на экране |
| «Порт 8787 занят другой программой» | В сообщении названа сама программа. Закройте её и запустите Макросыч снова |

## Первый сценарий — пять шагов

1. Вкладка **«Настройки»**: подключите нейросеть — адрес сервиса, название модели и ключ доступа.
   Кнопка «Проверить подключение» подтвердит, что всё работает. Без этого сценарий не составить:
   готовых сценариев в программе нет.
2. Вкладка **«Новая задача»**: приложите файл-образец (небольшой файл той же структуры,
   что и рабочие) и нажмите «Проанализировать файл».
3. Опишите задачу обычными словами и нажмите **«Составить сценарий»**. Посмотрите, что именно
   уйдёт в нейросеть, и подтвердите отправку.
4. Нажмите **«Проверить на образце»** — программа покажет таблицу с результатом и список файлов.
   Если что-то не так, уточните описание и составьте сценарий заново.
5. Сохраните сценарий в **«Библиотеку»** — дальше он запускается на новых файлах одной кнопкой.

Подробные разборы частых ситуаций — на вкладке **«Как пользоваться»** внутри программы.

## Обновление версии

Данные (сценарии, настройки, загруженные и готовые файлы) лежат отдельно от программы — в папке
`data`. Поэтому обновление не затрагивает вашу библиотеку:

1. Вкладка «О программе» → «Сохранить резервную копию данных» (страховка).
2. Скачайте новую версию и распакуйте её в отдельную папку.
3. Перенесите папку `data` из старой версии в новую — или новые файлы программы в старую папку.
4. Запустите `Макросыч.exe` и сверьте номер версии в шапке окна.

## Для разработчиков

В репозитории — только исходный код: `app/` (движок, HTTP API, интерфейс), `tools/` (утилиты,
проверки, сборка релиза), `launcher/` (лаунчер на C#, собирается встроенным в Windows
компилятором `csc.exe`). Бинарники (портативный PHP и библиотеки) в git не хранятся — они
попадают в релизный архив.

```bat
launcher\build.bat                                 :: собрать Макросыч.exe из launcher\Makrosych.cs
composer install --no-dev                          :: поставить PhpSpreadsheet в vendor/
runtime\php\php.exe tools\make_release.php --trim   :: собрать dist\makrosych-<версия>.zip
```

Сценарий — это JSON из готовых операций; движок не исполняет сгенерированный код. Новая операция
добавляется одним файлом в `app/Engine/Ops/` и сразу появляется в интерфейсе и в подсказке
для нейросети.
