Что делает Макросыч

        
Программа делает в Excel то, что обычно делают руками: переносит данные из
        одной таблицы в другую, собирает значения из нескольких строк в одну ячейку, подставляет
        данные из прайса по коду, считает итоги, убирает дубликаты, сортирует строки, строит
        диаграммы, наводит порядок в ссылках, скачивает файлы
        по ссылкам из таблицы, вставляет картинки и записывает формулы.

        
Работу вы описываете обычными словами, а сценарий по этому описанию
        составляет нейросеть. Поэтому перед первой задачей нужно подключить нейросеть —
        на вкладке «Настройки». Библиотека сценариев при установке пуста: готовых заготовок нет,
        у каждой компании свои таблицы и свои задачи.

        

            
Что такое сценарийЗапись однажды описанной работы: какие данные взять, что с ними сделать и куда положить. Описывается один раз, запускается сколько угодно раз.

            
Зачем нейросетьОна составляет сценарий по вашему описанию — вам не нужно разбираться в настройках операций. При запуске готового сценария нейросеть не участвует.

            
Где работают данныеНа вашем компьютере. При составлении сценария во внешний сервис уходит только образец таблицы — сколько строк отправлять, вы задаёте в настройках. При запуске сценария данные никуда не отправляются, кроме фотографий, которые сценарий сам скачивает по ссылкам из вашей таблицы.

            
Нужен ли интернетЧтобы составить сценарий — да: нужен интернет и подключённая нейросеть. Чтобы запускать уже созданные сценарии — нет, кроме тех, что сами скачивают файлы по ссылкам.

            
Права администратораНе нужны. Программу можно положить в любую папку, хоть на флешку.

        

    


    

        
Первый сценарий: пять шагов

        
Понадобится таблица, на которой будем пробовать. Лучше взять рабочий файл, но с небольшим числом строк.

        
    
            
  1. Откройте вкладку «Настройки» и подключите нейросеть: адрес сервиса, модель и ключ доступа. Кнопка «Проверить подключение» подтвердит, что всё работает. Без подключённой нейросети сценарий составить нельзя — готовых сценариев в программе нет, библиотека при установке пуста.
    2. 
            
  2. Откройте вкладку «Новая задача», выберите файл и нажмите «Проанализировать файл» — программа покажет, какие в файле колонки и какие в них данные. Перед этим укажите, сколько файлов нужно задаче: «один файл», если результат должен получиться в той же таблице, или «два файла» — тогда появится поле для справочника (прайса) или шаблона, и программа прочитает и его.
    3. 
            
  3. Опишите задачу обычными словами в поле «Описание задачи». Готовые примеры стоят прямо над полем: нажмите подходящий — текст подставится сам, его останется поправить под свою таблицу. Затем нажмите «Составить сценарий».
    4. 
            
  4. Нажмите «Проверить на образце» — программа покажет таблицу с результатом, то есть так, как будет выглядеть готовый файл. Если что-то не так, вернитесь к описанию и уточните задачу.
    5. 
            
  5. Если результат подходит, введите название и нажмите «Сохранить сценарий». Сценарий появится в библиотеке.
    6. 
        

        
Нейросеть нужна, чтобы составить сценарийОна собирает сценарий по вашему описанию, поэтому без подключения новый сценарий создать не получится. Зато потом, при запуске, нейросеть не участвует: сценарий работает без интернета и без оплаты.

    


    

        
Типовые задачи: что можно поручить Макросычу

        
Задачу описывайте своими словами — буквы колонок знать не обязательно:
        программа уже прочитала структуру вашей таблицы. Если задача составная, опишите её
        по шагам, как рассказали бы коллеге. Ниже — то, что чаще всего просят сделать.

        

            
Перенести данные«Перенеси данные из этой таблицы в шаблон: ключ — артикул, заполни колонки шаблона». Подойдёт, когда данные собираются из нескольких строк в одну.

            
Подтянуть из прайса (ВПР)«Подставь из файла-справочника наименование и цену по коду товара». Приложите второй файл в поле «Файл-справочник».

            
Свести несколько файлов«Собери данные из двух выгрузок одной структуры в один свод» — строки складываются в один файл.

            
Убрать дубликаты«Убери дубликаты: оставь по одной строке на артикул и напиши рядом, сколько раз он встретился».

            
Промежуточные итоги«Сделай как в Excel: строки данных и после каждого артикула строка «X Итог», в конце — общий итог».

            
Итоги по группам«Сложи суммы по артикулу: одна строка на артикул». Так же считаются среднее, количество и число различных значений.

            
Отсортировать«Разложи строки по сумме от большего к меньшему» или «по алфавиту».

            
ABC-анализ«Сделай ABC-анализ по артикулу: сумма, доля в процентах, накопленная доля и диаграмма».

            
Диаграмма«Построй диаграмму: подписи из артикула, значения из суммы» — столбчатая, линейная, круговая или площадная.

            
Прибыль и налоги«Добавь колонки «Прибыль» и «НДС» формулами: цена минус закупка, и цена с налогом». Формулы останутся в файле, их можно поправить.

            
Ссылки в одну ячейку«Собери ссылки из колонки в одну ячейку через перенос строки» — и обратная задача: «разложи ссылки из ячейки по строкам».

            
Ссылка на карточку«Поставь активную ссылку на карточку товара по коду, текст ячейки не меняй».

            
Фотографии«Вставь фото по ссылке в новую колонку рядом с кодом» или «возьми фото из папки по имени файла».

            
Скачать файлы«Скачай изображения по ссылкам из колонки в папки по артикулу» — понимает обычные ссылки, публичные папки Яндекс Диска и Облака Mail.ru (скачивает все файлы из папки, включая вложенные).

            
Навести порядок в тексте«Убери лишние пробелы, приведи к нижнему регистру, замени точки на запятые».

            
Пересчитать единицы«Переведи вес из килограммов в граммы, а размеры из метров в миллиметры».

            
Сравнить две таблицы«Покажи, чего нет в прайсе» или «что изменилось по сравнению с прошлой выгрузкой».

        

        
Если не получилось с первого разаОпишите задачу чуть подробнее или уточните, что именно не так — программа составит сценарий заново. Удачный сценарий сохраняется в библиотеку и дальше запускается одной кнопкой, уже без нейросети.

    


    

        
Как запускать сценарий на новых файлах

        
    
            
  1. Откройте вкладку «Библиотека» и найдите нужный сценарий.
    2. 
            
  2. Нажмите «Запустить» и приложите файлы: таблицу с данными и, если сценарий их использует, шаблон.
    3. 
            
  3. Если у сценария есть параметры (например, номер строки, с которой начинаются данные), заполните их.
    4. 
            
  4. Нажмите «Запустить» и дождитесь окончания работы. Готовые файлы скачиваются кнопкой, а все сразу — архивом.
    5. 
        

        
Кнопка «Образец» в карточке сценария показывает файл, на котором сценарий создавался: его колонки и первые строки. Файл можно скачать и открыть в Excel — удобно, чтобы вспомнить, для какой таблицы сценарий сделан.

    


    

        
Подключение нейросети

        
Заполняется один раз, на вкладке «Настройки». Нужны три вещи: адрес сервиса, название модели и ключ доступа. Это обязательный шаг: сценарии составляет нейросеть, поэтому без подключения новый сценарий создать не получится.

        

            
Какой сервис выбратьЛюбой, который вам понравится, — лишь бы у него был API. Чаще всего берут RouterAI (ChatGPT, Claude, Gemini и другие модели в одном месте, оплата в рублях) или Polza.AI (больше 400 моделей, пополнение картой российского банка). Работает и OpenRouter — модели разных производителей в одном API. Подойдёт и OpenAI, и любой другой сервис с OpenAI-совместимым API.

            
Сколько это стоитВы платите только за токены, которые нужны для составления сценария: обычно от нескольких копеек до десятков рублей за один сценарий. Деньги списываются с баланса, который вы пополнили на сайте выбранного сервиса, — автору программы платить не нужно. Запуск уже созданных сценариев бесплатен: нейросеть в нём не участвует.

            
Что подготовитьАдрес API (у RouterAI это https://routerai.ru/api/v1), ключ доступа из личного кабинета сервиса и название модели. Нужен интернет, и часть данных образца уходит в сервис.

            
Модель на своём компьютереLM Studio или Ollama — бесплатно, без интернета, данные не покидают компьютер. Адрес обычно http://127.0.0.1:1234/v1.

            
Какую модель выбратьПодойдёт любая модель, которая умеет следовать инструкциям. Лучше брать модель без режима рассуждений — обычно в названии есть instruct: модели «с рассуждениями» тратят время на размышления и часто отвечают пустым ответом. Разные модели по-разному справляются с составными задачами, поэтому попробуйте две-три и оставьте ту, которая точнее собирает ваши сценарии. Названия моделей у разных сервисов отличаются, поэтому удобнее выбрать из списка в настройках.

            
Как проверитьКнопка «Проверить подключение» в настройках. Рядом кнопка «Список моделей» — она показывает, какие модели предлагает сервис.

        

        
Ключ доступа — личныйКлюч хранится только на этом компьютере, не попадает в сценарии и в журналы работы. Передавать его коллегам не нужно: каждый настраивает своё подключение.

    


    

        
Если что-то не получилось


        

            Не подключается к нейросети
            
    
                
  1. Проверьте адрес сервиса. Для LM Studio и Ollama он заканчивается на /v1, например http://127.0.0.1:1234/v1.
    2. 
                
  2. Нажмите «Список моделей». Если список пришёл — адрес и ключ верны, дело в названии модели: скопируйте его из списка.
    3. 
                
  3. Если написано про сертификат — соединение проверяет антивирус или прокси. Добавьте адрес сервиса в его исключения. В Kaspersky это «Настройки» → «Защита» → «Проверка защищённых соединений» → исключения.
    4. 
                
  4. Проверьте, что ключ скопирован целиком, без лишних пробелов в начале и в конце.
    5. 
            

        


        

            Модель отвечает пустым ответом или думает очень долго
            
Так ведут себя модели «с рассуждениями»: они тратят весь лимит на размышления, и на ответ ничего не остаётся.

            
    
                
  1. Увеличьте «Лимит ответа, токенов» до 16384–32768.
    2. 
                
  2. Если не помогло — возьмите другую модель, без режима рассуждений (в названии обычно есть instruct).
    3. 
            

        


        

            Проверка на образце не прошла
            
В замечании указан номер шага и параметр, который нужно поправить — обычно это буква колонки или название листа. Уточните описание задачи и составьте сценарий заново.

            
Проверьте также, что образец похож на рабочие файлы: те же колонки, та же строка заголовков, те же листы.

        


        

            В шаблоне нет нужной колонки
            
Колонку можно добавить прямо в описании задачи, например: «вставь колонку «Изображение» перед колонкой B». Программа добавит её в шаблон и сдвинет остальные.

        


        

            Куда сохранились готовые файлы
            
В папку данных программы. Точный путь виден на вкладке «Настройки», раздел «Хранение данных», а открыть её можно кнопкой «Открыть папку данных» на вкладке «О программе».

        


        

            Как перенести программу на другой компьютер
            
Скопируйте папку программы целиком — вместе с папкой data. В ней лежат сценарии, настройки и готовые файлы, поэтому они переедут вместе с программой.

            
Перед обновлением версии сделайте резервную копию: вкладка «О программе» → «Сохранить резервную копию данных».

Макросыч — бесплатная программа для работы с таблицами

        
Макросыч делает в Excel то, что обычно делают руками: переносит данные из одной
        таблицы в другую, собирает значения из нескольких строк в одну ячейку, подставляет данные
        из прайса по коду, считает итоги, убирает дубликаты, сортирует строки, строит диаграммы,
        наводит порядок в ссылках, скачивает файлы по ссылкам
        из таблицы, вставляет фотографии и записывает формулы.

        
Задачу вы описываете обычными словами, а сценарий составляет нейросеть —
        поэтому перед первой задачей её нужно подключить на вкладке «Настройки». Готовых сценариев
        в программе нет: библиотека при установке пуста. Зато дальше сценарий запускается на новых
        файлах одной кнопкой — без интернета и без нейросети.

        
Программа бесплатная: без рекламы, без подписки и без сбора данных — все ваши
        файлы остаются на вашем компьютере.

        

            Сначала загляните в «Как пользоваться»
            Там шесть разборов частых ситуаций: не подключается нейросеть, модель отвечает пустым
            ответом, не прошла проверка на образце, в шаблоне нет нужной колонки, куда сохранились
            готовые файлы, как перенести программу на другой компьютер. Обычно ответ находится
            там за минуту, а письма пришлось бы ждать.
